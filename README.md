# Technical screening

## Prerequisites

- Node.js >= 20 (see `.nvmrc`)
- A GitHub account

## Setup

You can't push to this repository. Work on your own copy instead:

1. **Fork** this repository into your own GitHub account or organization. Use the "Fork" button at the top right of the [repository page](https://github.com/quarzo-life/technical-screening-starter-project).
2. **Clone your fork**. Don't clone this repository:

   ```sh
   git clone git@github.com:<your-account>/technical-screening-starter-project.git
   cd technical-screening-starter-project
   ```

3. **Install dependencies**:

   ```sh
   npm install
   ```

Commit and push your work to your fork.

## Commands

```sh
npm test            # run tests once
npm run test:watch  # run tests in watch mode
npm run typecheck   # type-check with tsc
npm run format      # format with Prettier
```
